# mixRSMflow: Integrated Mixture Experiment Workflows

Design, model, diagnose, optimize, quantify uncertainty, and visualize
mixture experiments with explicit constraints and auditable scientific
semantics.

## Details

The package covers classical Scheffe mixture methodology, constrained
regions, mixture-process designs, optimal design, multiresponse
optimization, uncertainty in optimum location, and modern optional
extensions. See the package vignettes for complete workflows.
