### 1. Why an extended vignette on alternative mixture models?

Scheffé polynomials are the natural starting point for mixture response
surfaces, but they do not exhaust the scientifically useful ways to
express blending behavior. Some formulation problems involve ratios,
substitutions around a reference composition, a dominant slack
component, inverse behavior near small proportions, grouped blend laws,
or response regimes that change at a component threshold.

The important question is not “Which formula gives the highest
R-squared?” It is:

**Which model basis expresses a scientifically plausible blending
mechanism over the actually observed mixture region while remaining
estimable, stable, and interpretable?**

`mixRSMflow` makes the basis explicit through
[`mix_basis()`](https://wep69.github.io/mixRSMflow/reference/mix_basis.md).
This is central to transparent mixture modeling because users can
inspect the columns before fitting them.

14. compare alternative models through prediction, diagnostics,

### 5. Scheffé quadratic as the reference basis

``` r

Xq <- mix_basis(
  x,
  sp,
  model = "scheffe_quadratic"
)

head(Xq)
colnames(Xq)
```

For three components the familiar basis is

``` math
[x_1,x_2,x_3,x_1x_2,x_1x_3,x_2x_3].
```

The coefficient values are attached to these constrained basis
functions. They are not ordinary slopes from three independent factors.

Fit the reference model:

``` r

m_q <- mix_fit(
  "response",
  d,
  sp,
  model = "scheffe_quadratic"
)
```

Every alternative considered below should be compared with an explicit
scientific reference like this rather than with an undefined “default
model.”

## Part II. Slack-variable models

### 6. Why use a slack component?

Because

``` math
x_A+x_B+x_C=1,
```

one component can be written as a remainder. If C is the slack
component,

``` math
x_C=1-x_A-x_B.
```

Construct the basis:

``` r

X_slack <- mix_basis(
  x,
  sp,
  model = "slack_quadratic",
  slack_component = "C"
)

head(X_slack)
```

Fit directly:

``` r

m_slack <- mix_fit(
  "response",
  d,
  sp,
  model = "slack_quadratic",
  slack_component = "C"
)
```

#### 6.1 Reparameterize an existing fit

``` r

m_repar <- mix_reparameterize(
  m_q,
  slack_component = "C"
)

m_repar
```

#### Interpretation

A slack-variable representation can make a substitution story easier to
tell when one material is naturally the balancing carrier. For example,
if A and B are two active nutrient sources and C is an inert carrier,
increasing A at fixed B necessarily displaces C.

Do not choose the slack component after inspecting coefficient
significance. Choose it because the formulation process makes that
component a meaningful remainder.

## Part III. Inverse terms

### 7. Construct an inverse-term basis

Inverse terms can express sharp response changes at small component
amounts.

``` r

x_pos <- x[
  x$A > 0 & x$B > 0 & x$C > 0,
]

X_inv <- mix_basis(
  x_pos,
  sp,
  model = "inverse_scheffe",
  inverse_components = c("A", "B")
)

head(X_inv)
```

#### 7.1 Scientific interpretation

An inverse component term implies behavior that changes rapidly as a
component approaches zero. This may be plausible in examples where a
tiny amount of an essential binder, catalyst, stabilizer, micronutrient
carrier, or biological inoculant produces a large response difference.

#### 7.2 Numerical danger

If `x_i` approaches zero,

``` math
1/x_i\to\infty.
```

Therefore:

- the design must have a strictly positive lower bound for that
  component;
- near-zero points can dominate the fit;
- prediction outside the observed positive range can be extreme;
- standard errors can become unstable.

#### 7.3 Agronomic example

A seed coating contains a small biological adhesive fraction A. If
adhesion fails rapidly below a minimum amount, an inverse-style term may
represent the sharp transition more directly than a smooth low-degree
polynomial.

This should be a mechanistic hypothesis, not a post-hoc attempt to
improve fit statistics.

## Part IV. Ratio models

### 8. Ratios as scientific predictors

Nutrient and formulation science often uses ratios such as N:K,
protein:energy, or active:carrier.

``` r

X_ratio <- mix_basis(
  x_pos,
  sp,
  model = "ratio",
  denominator = "A"
)

head(X_ratio)
```

#### 8.1 Denominator choice

The denominator is part of the model definition. Choosing A versus B
changes the numerical representation and scientific comparison.

Avoid denominator components that can become zero or extremely small.

#### 8.2 Interpretation example

If A is total N carrier, the ratio `B/A` can represent a secondary
nutrient relative to N. This can have a direct agronomic interpretation
unavailable from a generic pairwise product.

#### 8.3 Common mistake

Do not interpret a statistically large ratio coefficient as evidence
that the denominator is biologically unimportant. Ratio predictors mix
information from numerator and denominator.

## Part V. Cox mixture coordinates

### 9. Reference-blend thinking

Cox parameterizations express movement relative to a reference blend.

``` r

ref <- c(A = 0.30, B = 0.30, C = 0.40)

X_cox1 <- mix_basis(
  x,
  sp,
  model = "cox_linear",
  reference = ref
)

X_cox2 <- mix_basis(
  x,
  sp,
  model = "cox_quadratic",
  reference = ref
)

X_cox3 <- mix_basis(
  x,
  sp,
  model = "cox_cubic",
  reference = ref
)
```

#### Interpretation

A reference blend can be:

- a current commercial formulation;
- a standard fertilizer composition;
- the geometric center of the feasible region;
- a formulation chosen before experimentation because it has operational
  importance.

Do not choose the reference solely to obtain smaller standard errors.

#### Companion interpretation

Cox **component-effect paths** are covered in the component-effects
material. Here Cox is treated as a model parameterization.

## Part VI. Log-contrast models

### 10. Compositional log contrasts

For positive proportions, log ratios can represent relative composition.

``` r

X_log <- mix_basis(
  x_pos,
  sp,
  model = "logcontrast",
  reference = "A"
)

head(X_log)
```

#### 10.1 Positivity requirement

A logarithm is undefined at zero. If a component is allowed to be
absent, an ordinary log-contrast basis cannot be applied without an
explicit zero-handling model.

Do **not** silently add a small constant just to make the code run. That
changes the scientific model.

#### 10.2 Interpretation

Log contrasts are naturally interpreted through relative changes. For
example, an increase in `log(B/A)` means B increases relative to A.

This can be scientifically compelling in nutrient balance or
compositional chemistry, but it differs from Scheffé blending
interpretation.

## Part VII. Becker model families

### 11. H1, H2, H3 bases

``` r

X_H1 <- mix_basis(x, sp, model = "becker_h1")
X_H2 <- mix_basis(x, sp, model = "becker_h2")
X_H3 <- mix_basis(x, sp, model = "becker_h3")
```

These families provide alternative homogeneous blending structures.

#### Teaching strategy

Rather than memorizing labels, inspect:

``` r

colnames(X_H1)
colnames(X_H2)
colnames(X_H3)
```

and compare the basis values for the same blends.

#### Interpretation

Different bases can describe similar fitted surfaces while attaching
different meanings and scaling to coefficients. Therefore coefficient
tables should not be compared term-by-term across model families as if
they were the same estimands.

## Part VIII. Additive blending

### 12. A component with a distinct additive role

``` r

X_add <- mix_basis(
  x,
  sp,
  model = "additive_blending",
  additive_component = "C"
)

head(X_add)
```

This is useful when one component is hypothesized to contribute in a

complex blending behavior.

#### Agronomic example

A substrate mixture may combine two biologically active organic
fractions while a mineral carrier contributes primarily through a
near-additive physical effect.

Again, the hypothesis should be declared scientifically, not inferred
only from coefficient significance.

## Part IX. General Blending Model

### 13. Why explicit GBM terms?

The General Blending Model can encompass several familiar mixture terms
through fixed exponents.

Create a binary term:

``` r

term_AB <- mix_gbm_term(
  components = c("A", "B"),
  g = c(2, 2),
  h = 0.5,
  s = 2,
  label = "AB"
)

term_AB
```

Use it:

``` r

X_gbm <- mix_basis(
  x,
  sp,
  model = "gbm",
  gbm_terms = list(term_AB)
)

head(X_gbm)
```

For a binary term, the implemented fixed-exponent form is

``` math
\left(\frac{x_i}{x_i+x_j}\right)^{g_i h}
\left(\frac{x_j}{x_i+x_j}\right)^{g_j(1-h)}
(x_i+x_j)^s.
```

------------------------------------------------------------------------

### 14. Recovering the Scheffé cross-product

Set:

``` math
g_i=g_j=2,\quad h=1/2,\quad s=2.
```

Then the term becomes

``` math
x_ix_j.
```

Check numerically:

``` r

term_scheffe <- mix_gbm_term(
  c("A", "B"),
  g = c(2, 2),
  h = 0.5,
  s = 2,
  label = "AB_identity"
)

G <- mix_basis(
  x,
  sp,
  model = "gbm",
  gbm_terms = list(term_scheffe)
)

max(abs(G[, ncol(G)] - x$A * x$B))
```

This identity is useful as a validation target because it connects the
advanced GBM implementation with a known classical basis.

------------------------------------------------------------------------

### 15. Fixed exponents are deliberate

[`mix_fit()`](https://wep69.github.io/mixRSMflow/reference/mix_fit.md)
does not silently estimate the nonlinear GBM exponents.

Why?

- nonlinear exponent estimation changes the optimization problem;
- identifiability may be weak;
- standard linear-model inference no longer applies directly;
- hidden nonlinear estimation would make the basis difficult to audit.

Users explicitly define the exponents or use a dedicated nonlinear
workflow outside the ordinary linear fit.

This is a methodological transparency feature, not a missing
convenience.

## Part XI. Fit and compare alternative bases

### 17. A reproducible comparison dataset

``` r

d <- mix_demo_data(
  "mixture",
  n_rep = 3,
  seed = 26101
)
```

Fit several plausible candidates:

``` r

m1 <- mix_fit(
  "response", d, sp,
  model = "scheffe_quadratic"
)

m2 <- mix_fit(
  "response", d, sp,
  model = "cox_quadratic",
  reference = c(A = 0.33, B = 0.33, C = 0.34)
)

m3 <- mix_fit(
  "response", d, sp,
  model = "slack_quadratic",
  slack_component = "C"
)
```

Compare:

``` r

mix_compare(m1, m2, m3, criterion = "PRESS")
```

#### Comparison rules

Do not decide from one number. Also inspect:

``` r

mix_diagnose(m1)
mix_diagnose(m2)
mix_diagnose(m3)

mix_collinearity(m1)
mix_collinearity(m2)
mix_collinearity(m3)
```

and compare predicted surfaces over the same feasible region.

------------------------------------------------------------------------

### 18. Prediction equivalence versus coefficient equivalence

Two parameterizations can generate very similar fitted surfaces while
producing very different coefficients.

A good comparison asks:

- Are fitted values nearly identical?
- Are predictions at scientifically important blends similar?
- Is one basis more stable numerically?
- Does one basis answer a clearer scientific question?
- Does a reparameterization merely relabel the same model space?
- Does an alternative basis introduce genuinely different curvature or
  boundary behavior?

This distinction prevents overinterpretation of coefficient tables.

## Part XII. Model reduction

### 19. Start from a larger hierarchical candidate

``` r

m_big <- mix_fit(
  "response",
  d,
  sp,
  model = "scheffe_special_cubic"
)
```

Reduce:

``` r

red <- mix_reduce(
  m_big,
  criterion = "hybrid",
  max_steps = 25
)

red
```

Compare:

``` r

mix_compare(
  m_big,
  red$fit,
  criterion = "PRESS"
)
```

#### Interpretation

Reduction is appropriate when the design supports a larger candidate
space but the data provide little evidence for all terms.

It is not appropriate to remove lower-order structure that is required
for a coherent hierarchical interpretation merely because an individual
p-value is large.

## Part XIII. Segmented mixture surfaces

### 20. Why segmentation?

Some blending systems exhibit a pre-specified regime change. Examples:

- a binder becomes continuous above a critical proportion;
- a biochar fraction changes water-retention behavior above a physical
  threshold;
- a surfactant passes a formulation boundary;
- a nutrient carrier changes phase or solubility regime.

A single global polynomial can blur that change.

------------------------------------------------------------------------

### 21. Fit two regimes

``` r

d_seg <- mix_demo_data(
  "mixture",
  n_rep = 3,
  seed = 26201
)

seg <- mix_segmented_fit(
  response = "response",
  data = d_seg,
  spec = sp,
  split_component = "A",
  cut = 0.50,
  model_left = "scheffe_linear",
  model_right = "scheffe_quadratic"
)

seg
```

Predict:

``` r

p_seg <- mix_predict_segmented(
  seg,
  interval = "confidence",
  level = 0.95
)

head(p_seg)
```

#### Critical safeguard

The cut should ideally be pre-specified from science or investigated
under a clearly documented model-selection strategy. Searching dozens of
cuts and reporting the best without accounting for selection uncertainty
can seriously overfit the surface.

## Part XIV. An agronomic ratio-model case study

### 22. Nutrient-solution formulation

Suppose a nutrient source is composed of:

- nitrate-dominant source `NO3`;
- ammonium-dominant source `NH4`;
- organic N source `OrgN`.

The total N-source fraction is one, but the biological hypothesis
focuses on the ammonium-to-nitrate ratio.

``` r

sp_N <- mix_spec(
  c("NO3", "NH4", "OrgN"),
  lower = c(0.10, 0.05, 0.05)
)
```

Create a design before outcomes using the design-focused documentation.
After data collection:

``` r

set.seed(26301)

dN <- mix_design(
  sp_N,
  type = "simplex_lattice",
  degree = 4
)$data

# Teaching response only.
dN$biomass <- with(
  dN,
  40 +
  5 * log(NH4 / NO3) -
  3 * (OrgN - 0.25)^2 +
  rnorm(nrow(dN), 0, 1.5)
)
```

Fit a log-contrast candidate:

``` r

m_log <- mix_fit(
  "biomass",
  dN,
  sp_N,
  model = "logcontrast",
  reference = "NO3"
)
```

Fit a Scheffé reference:

``` r

m_sch <- mix_fit(
  "biomass",
  dN,
  sp_N,
  model = "scheffe_quadratic"
)
```

Compare prediction and diagnostics rather than only p-values:

``` r

mix_compare(m_sch, m_log, criterion = "PRESS")
mix_diagnose(m_sch)
mix_diagnose(m_log)
```

#### Interpretation

If the log-contrast model performs well and the ratio has direct
biological meaning, it may be more interpretable than a generic
polynomial. If zeros are scientifically possible, however, the log model
requires a different treatment and should not be forced.

## Part XV. A blending-model decision framework

### 23. Ask these questions before changing model family

1.  Is the current Scheffé model demonstrably inadequate?
2.  Is there a mechanistic reason for the alternative basis?
3.  Does the design support the new columns?
4.  Are any transformations singular near the observed boundary?
5.  Does the alternative improve prediction at scientifically important
    blends?
6.  Does it reduce or increase conditioning problems?
7.  Can the coefficients be explained to a domain scientist?
8.  Is the apparent improvement caused by one high-leverage formulation?
9.  Does the fitted optimum remain stable?
10. Does the model behave plausibly on every feasible boundary?

## Part XVI. Common mistakes

### 24. Using inverse terms with zero components

Do not.

------------------------------------------------------------------------

### 25. Adding a pseudocount to enable log contrasts without saying so

That changes the model and the science.

------------------------------------------------------------------------

### 26. Choosing the ratio denominator after looking at significance

Predefine the scientific ratio whenever possible.

------------------------------------------------------------------------

### 27. Comparing coefficients across different bases as if they had the same meaning

Compare fitted response behavior and model-specific estimands.

------------------------------------------------------------------------

### 28. Estimating GBM exponents implicitly

The current linear workflow uses explicit fixed exponents by design.

------------------------------------------------------------------------

### 29. Selecting a segmented cut only by minimum residual sum of squares

Use scientific justification and account for search uncertainty.

------------------------------------------------------------------------

### 30. Reducing hierarchy until every remaining p-value is below 0.05

Model reduction should combine hierarchy, prediction, design support,
diagnostics, and scientific meaning.

## Part XVII. Function-selection guide

| Scientific feature | Start with |
|:---|:---|
| Conventional smooth blending | Scheffé through [`mix_fit()`](https://wep69.github.io/mixRSMflow/reference/mix_fit.md) |
| Natural remainder/carrier component | `slack_*` or [`mix_reparameterize()`](https://wep69.github.io/mixRSMflow/reference/mix_reparameterize.md) |
| Strong behavior at small positive component | `inverse_scheffe` |
| Mechanistic relative component ratio | `ratio` |
| Interpretation around a reference blend | `cox_*` |
| Relative/compositional log interpretation | `logcontrast` |
| Homogeneous alternative blending | `becker_h1/h2/h3` |
| Distinct additive role for one component | `additive_blending` |
| Explicit fixed-exponent blending law | `gbm` + [`mix_gbm_term()`](https://wep69.github.io/mixRSMflow/reference/mix_gbm_term.md) |

| Predefined response-regime threshold | [`mix_segmented_fit()`](https://wep69.github.io/mixRSMflow/reference/mix_segmented_fit.md) |

## Part XVIII. Reporting checklist

mixture region and bounds;

full name of model basis;

basis columns or formula definition;

reference blend for Cox models;

denominator for ratio models;

positivity conditions for log/inverse models;

slack component if used;

Becker family designation;

all GBM exponents and labels;

segmented component and cut;

whether cut was pre-specified;

model rank and condition number;

lack of fit/pure error where available;

prediction criterion used in comparisons;

diagnostic findings;

behavior near feasible boundaries;

effect of model choice on optimum location;

explicit distinction between parameterization and genuinely different
model space.

## Final perspective

Alternative mixture models are useful when they express a better
scientific question, not merely when they fit more flexibly.

A rigorous sequence is:

**scientific blending hypothesis -\> explicit basis -\> design support
-\> fit -\> diagnostics -\> predictive comparison -\> boundary behavior
-\> interpretation -\> optimization sensitivity.**

## Appendix C. Advanced alternative-model laboratories

### C1. Laboratory: same surface, different parameterization

Fit a Scheffé quadratic model and a slack-variable reparameterization.
Compare fitted values at all observed blends.

``` r

sp_lab <- mix_spec(c("A", "B", "C"))
d_lab <- mix_demo_data("mixture", n_rep = 3, seed = 261001)

m1 <- mix_fit("response", d_lab, sp_lab, "scheffe_quadratic")
m2 <- mix_reparameterize(m1, slack_component = "C")

p1 <- fitted(m1)
p2 <- fitted(m2)

max(abs(p1 - p2))
```

#### Lesson

If fitted values are equivalent, coefficient differences reflect
parameterization rather than a new response surface. The methods section
should not describe the reparameterized form as empirical evidence for a
different biological mechanism.

------------------------------------------------------------------------

### C2. Laboratory: instability near zero

Create a positive dataset with A values approaching zero. Compare an
inverse-term basis and a Scheffé basis.

#### Tasks

- inspect maximum absolute basis values;
- compare condition numbers;
- remove the near-zero point and repeat;
- explain why an inverse term can make a single formulation dominate the
  fit.

The exercise teaches that functional plausibility and numerical
stability must be evaluated together.

------------------------------------------------------------------------

m_ratio <- mix_fit(

## Appendix D. Alternative-model troubleshooting matrix

| Symptom | Likely cause | Response |
|:---|:---|:---|
| `Inf`/huge inverse terms | component near zero | impose scientifically justified positive bound or reject model |
| log model fails | zero/nonpositive component | do not add arbitrary pseudocount silently |
| ratio model unstable | denominator near zero | choose scientifically stable denominator or alternative model |
| Cox coefficients change greatly with reference | reference-dependent parameterization | report reference and compare predictions |
| different bases have similar predictions | reparameterization/equivalent flexibility | interpret model-specific coefficients carefully |
| GBM basis seems opaque | exponents not documented | report every `g`, `h`, `s`, label |
| segmented fit overly good | cut selected post hoc | account for search/overfitting and justify threshold |
| reduction removes meaningful hierarchy | automatic criterion too aggressive | protect lower-order terms scientifically |

## Appendix H. Applied alternative-model case bank

### H1. Nutrient ratio mechanism

A hydroponic response depends strongly on ammonium relative to nitrate
rather than on either absolute fraction in isolation. A ratio or
log-contrast basis can match the biological question more closely than a
generic quadratic Scheffé polynomial. The denominator must remain safely
above zero, and the chosen ratio must be justified before significance
is examined. If the ratio model predicts similarly to the Scheffé model
but offers clearer biological interpretation, that interpretability can
be a legitimate reason to prefer it.

### H2. Essential low-dose binder

A coating requires a small binder fraction. Adhesion fails sharply when
binder approaches its lower admissible level. An inverse term may
reflect this steep behavior, but it also magnifies small numerical
errors near zero. The component should have a scientifically justified
positive lower bound. The analyst should inspect condition number,
leverage, and boundary predictions before accepting the inverse
formulation.

### H3. Commercial reference formulation

A company evaluates substitutions around an existing product. Cox
coordinates can center interpretation around the commercial blend rather
than around pure vertices that are never manufactured. The reference
should be reported in the original mixture units. Changing the reference
can change coefficients while leaving much of the fitted surface
unchanged, so reference sensitivity should be understood as
parameterization sensitivity rather than evidence of biological
instability.

### H4. Regime change in substrate physics

Above 35% biochar, water-retention behavior may enter a different
physical regime. If that threshold is supported by prior physical
knowledge, a segmented surface can represent different response laws on
either side. If the threshold is found only by searching all possible
cuts, model-selection uncertainty becomes important and the apparently
sharp transition may be overfit.

### H5. Fixed-exponent GBM for mechanistic blending

A mechanistic formulation hypothesis implies a known homogeneity
structure.
[`mix_gbm_term()`](https://wep69.github.io/mixRSMflow/reference/mix_gbm_term.md)
allows explicit exponents so the basis is transparent. The analyst can
verify classical identities and inspect columns before fitting. Hidden
nonlinear estimation of exponents would obscure identifiability and
change inference, so the package deliberately requires them to be
supplied in the ordinary linear workflow.

## Appendix I. Short-answer alternative-model review

1.  **What is the first diagnostic for an alternative model?** Inspect
    the actual basis columns.
2.  **Why are inverse terms risky?** They diverge as a component
    approaches zero.
3.  **Why are log contrasts impossible at zero?** `log(0)` is undefined.
4.  **Does changing Cox reference change the physical mixtures?** No; it
    changes coordinates/parameter interpretation.
5.  **When is a slack model natural?** When one component is an
    operational remainder.
6.  **What must accompany a ratio model?** The denominator and its
    admissible range.
7.  **What are GBM exponents in this workflow?** Explicit fixed inputs.
8.  **Is lower PRESS proof of mechanistic truth?** No; it is evidence
    about predictive performance under the comparison.
9.  **Why inspect boundary predictions?** Alternative terms can behave
    strongly near zero or constraints.
10. **When is segmentation defensible?** When the regime boundary has
    scientific support or selection is handled transparently.

## Appendix J. Deeper conceptual notes on model meaning

### J1. Parameterization, estimand, and prediction

Three levels should be separated when comparing mixture models.
**Parameterization** concerns how a given response surface is expressed
in coefficients. **Estimand** concerns what scientific quantity those
coefficients or derived contrasts represent. **Prediction** concerns the
fitted response at a composition. Two parameterizations can have very
different coefficient tables and nearly identical predictions.
Conversely, two bases can look algebraically similar but imply different
boundary behavior and therefore different scientific conclusions.

A good model-comparison report therefore presents at least one quantity
from each level: the explicit basis, an interpretable effect or
coefficient statement, and predicted response behavior over the common
feasible region. This is more informative than listing only AIC or
R-squared.

### J2. Boundary behavior is part of model choice

Mixture optimization frequently pushes fitted surfaces toward edges or
vertices. Alternative models that behave innocently in the interior can
behave dramatically near zero components. Inverse, ratio, and log terms
deserve particularly careful boundary evaluation. Before adopting such a
model, create a dense feasible grid and inspect predicted response as
each affected component approaches its minimum admissible value. A model
that produces implausible divergence within the experimental region
should not be retained merely because the global residual sum of squares
is small.

### J3. Scientific parsimony

Parsimony in mixture modeling is not synonymous with the fewest columns.
A model with fewer but difficult-to-interpret singular terms may be less
scientifically parsimonious than a slightly larger Scheffé model whose
behavior is stable and transparent. Likewise, a mechanistically
motivated ratio model can be more parsimonious scientifically even when
it has comparable numerical dimension. The decision should balance
interpretability, prediction, design support, and stability.

### J4. Design dependence

A model family cannot be evaluated independently of the design that
generated the data. A ratio or GBM term may be weakly identified if the
design never varies the relevant composition contrast. A segmented model
cannot estimate both regimes well if only a few points lie on one side
of the cut. When an alternative model appears unstable, ask whether the
problem is the basis or inadequate experimental support. Extended
Vignette 25 explains how the design can be optimized for a declared
model basis.

### J5. Recommended analysis narrative

A strong manuscript narrative might proceed as follows:

1.  state the classical reference basis;
2.  state the scientific reason for considering the alternative;
3.  define every reference, denominator, slack component, threshold, or
    GBM exponent;
4.  show that the design supports the basis;
5.  compare diagnostics and prediction on a common region;
6.  interpret the alternative in its own coordinate system;
7.  evaluate whether the practical optimum or decision changes;
8.  retain the simpler or clearer model when improvements are
    negligible.

This sequence makes alternative-model use auditable and avoids the
impression of formula shopping.
